# 浙江教师招聘岗位匹配工具

输入个人档案（户籍、学历、专业、教资、荣誉等），自动匹配浙江省内可报考的教师招聘岗位。

## 功能

- 覆盖幼儿园 / 小学 / 初中 / 高中 四学段
- 支持按城市、批次（提前批 / 社招）、编制类型筛选
- 匹配结果分三档：可报 / 待确认 / 不符，并说明原因
- 岗位数据来自浙江省各地教育局/政府官网公开招聘公告，附来源链接

纯前端：HTML + CSS + JavaScript，无需后端。
